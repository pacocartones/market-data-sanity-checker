# Notes for agents

This repository follows the maintainer's shared standard for repositories (standards v2). The
community files it inherits (Code of Conduct, SUPPORT, issue and pull request defaults) live in
[pacocartones/.github](https://github.com/pacocartones/.github) and are not in a clone, so read them
there.

Repository-specific rules come first and are in this repository:

- [CONTRIBUTING.md](CONTRIBUTING.md): setup, the rule contract, branch names and commit identity.
- [RELEASING.md](RELEASING.md): versions, changesets, tags (including the moving `v1`) and release notes.
- [AI_POLICY.md](AI_POLICY.md) and [GOVERNANCE.md](GOVERNANCE.md): agents draft, a human maintainer
  reviews every pull request, and only a human merges.

Maintainer commits carry no AI trailer or footer, and neither do pull request bodies or comments.
